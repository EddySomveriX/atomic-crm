# «Автоповідомлення» — итоги

Согласовано 2026-11-16 («Ок, делай все по порядку»), второй пакет улучшений. Ветка `improvements`.

## Решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Какие сценарии | Пять готовых: отзыв после визита, «час повторити», после пропущенного визита, «давно не було», день рождения |
| 2 | Как включать | Переключатель у каждого; по умолчанию всё выключено |
| 3 | Сколько раз | Каждое сообщение — один раз (журнал `automation_sends` с уникальным ключом) |
| 4 | Когда | С 9:00 до 20:00 по времени бизнеса |
| 5 | Кому | Только клиентам с чатом в Telegram, которые согласились с условиями бота |
| 6 | Отписка | Клиент пишет «стоп» (или stop, /stop) — больше автоматических сообщений нет |
| 7 | Текст | Стандартный или свой; строку про «стоп» бот добавляет всегда |

## Сделано

- **База** (`supabase/schemas/22_automations.sql`, миграции `20261121100000_automations.sql`, `20261121110000_products_rebook_days.sql`, `20261121120000_companies_summary_client_fields.sql`):
  - `automations` — настройки сценариев бизнеса (вкл/выкл, дни, ссылка на отзыв, свой текст);
  - `automation_sends` — журнал: кому, что, когда, доставлено ли;
  - у услуги `rebook_days` (через сколько дней повторить), у клиента `birth_date`, у чата `automations_off_at` («стоп»);
  - `claim_due_automations()` — отбирает и закрепляет подошедшие сообщения (только сервер);
  - в `companies_summary` добавлены поля карточки клиента: персональная скидка (раньше не показывалась после перезагрузки), выбор надёжности, день рождения.
- **Сервер**: `automations_run` раз в минуту отправляет подошедшие сообщения (локально его вызывает `scripts/channels-dev.mjs`); у «час повторити», «після пропуску» и «давно не було» — кнопка «Записатися».
- **Бот**: «стоп» отключает автосообщения для этого чата и отвечает подтверждением.
- **Экран «Автоповідомлення»** (меню «Чати» → «Автоповідомлення», на телефоне — ссылка со страницы чатов): пять переключателей, настройки (дни для каждой услуги, ссылка на отзыв, дни «давно не було»), образец текста с примером, свой текст, последние отправки.
- **Карточка клиента**: поле «День народження».

## Проверка

- Тесты базы: новые 12 (`automations.test.sql`), все остальные проходят. Интерфейс и функции: 622.
- В браузере: экран, включение сценария, дни услуги сохраняются, образец текста, поле дня рождения в карточке.

## Ограничения

- Живую отправку проверить вместе с владельцем бота: включить «Відгук після візиту» и отметить запись выполненной.
- Подарок или скидка ко дню рождения — пока только текстом.
- Карточка клиента на телефоне пока без дня рождения, скидки и надёжности (они видны на компьютере).
