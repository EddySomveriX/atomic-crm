Согласовано 2026-11-15 («да, принимаем»). Ветка `ui-modules`.

## Решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Телефон | Снизу: «Сьогодні», два первых раздела, «+», «Ще» (остальное и налаштування). Меню слева — на планшете и компьютере |
| 2 | Правило «меню из 5 пунктов» | Заменено: в меню только включённые модули; на телефоне 4 + «Ще» |
| 3 | Всегда включены | «Сьогодні», «Контрагенти», «Налаштування» |
| 4 | Запис | Отдельный модуль с календарём и графіком |
| 5 | Объём | Меню, модули, мастер, налаштування, вид (логотип, цвет и стиль меню, шрифт), аналитика |

## Сделано

- **Модули** (`supabase/schemas/17_modules.sql`, миграция `20261117100000_modules.sql`): `businesses.modules`, набор по виду бизнеса (`default_modules`), меняет только владелец. Во фронтенде — `modules/modules.ts` (разделы меню и их страницы), `useModules`.
- **Меню слева** (`layout/Sidebar.tsx`): «+ Створити» (пункты по модулям), «Пошук», разделы, подразделы открытого раздела, счётчик ожидающих у «Чати», «Налаштування», профиль, тема, сворачивание до значков (запоминается на устройстве). Старое верхнее меню удалено.
- **Телефон** (`layout/MobileNavigation.tsx`): нижняя панель по модулям.
- **Выбор модулей** (`modules/ModulesPicker.tsx`): строки с переключателем и описанием, рядом живая копия меню. В мастере создания бизнеса (после вида бизнеса) и в «Налаштування → Модулі». Выключение только прячет раздел.
- **Вигляд** (`appearance/`): логотип картинкой (уменьшается до 320 px и хранится в настройках бизнеса), отдельный логотип для тёмного меню, меню «кольорове» или «світле», 6 цветов (контраст проверен), 5 шрифтов с кириллицей (Onest, Manrope, Golos Text, Montserrat, Nunito; файлы шрифта грузятся только при выборе).
- **Справи**: страница `/tasks` на компьютере.
- **Сьогодні** показывает блоки только включённых модулей.
- **Аналітика** (`supabase/schemas/18_analytics.sql`, функция `business_analytics()`; страница `analytics/AnalyticsPage.tsx`): 12 блоков, период (месяц, прошлый месяц, 3 месяца, год) в адресе страницы, любой блок прячется, «Налаштувати» возвращает (выбор запоминается на устройстве для человека). Цвета графиков проверены валидатором на дальтонизм и контраст в светлой и тёмной теме; у графиков есть вид таблицей.
- Выручка до этапа 4 (оплаты) = выигранные сделки + выполненные записи по цене услуги.

## Ограничения

- Спрятанные блоки аналитики и свёрнутое меню запоминаются на устройстве, а не в аккаунте.
- Валюта аналитики — валюта бизнеса; сделки в другой валюте не считаются.
- Логотип пока только в меню; на документах — с этапа 4.
