# Переписка через мессенджеры — план

Запрошено 2026-11-16: переписываться с клиентами не только в Telegram, но и в Viber, WhatsApp, Instagram, Facebook и других каналах. Код не начат: сначала ответы владельца.

## Что получит владелец

- Все переписки — в одном разделе «Чати», у каждой значок канала; фильтр по каналу.
- Один клиент — одна карточка: чаты одного человека из разных мессенджеров связываются по телефону; на карточке клиента кнопка «Написати» с выбором канала.
- Бот записи, напоминания и автосообщения работают в том канале, где клиент написал.
- Файлы и фото из любого канала сохраняются в «Документи» той же кнопкой.

## Главное условие: адрес в интернете

Instagram, Facebook, WhatsApp и Viber доставляют сообщения только на публичный адрес в интернете (в отличие от Telegram, который на этом компьютере опрашивается раз в несколько секунд). Сейчас CRM работает только на компьютере владельца. Поэтому живое подключение этих каналов возможно после размещения серверной части в облаке Supabase (есть бесплатный тариф). То же нужно для публикации постов в Instagram.

## Как это устроено внутри

1. **Единый слой каналов.** Виды каналов расширяются: `instagram`, `messenger`, `whatsapp`, `viber`. Секреты каждого — только на сервере (`channel_secrets`).
2. **Коннекторы** в `/connectors`: `meta` (Instagram Direct, Messenger и WhatsApp используют один Graph API и одну подпись) и `viber`. Каждый умеет: проверить подпись входящего запроса, разобрать его в общий вид «кто, в каком чате, что написал, какие файлы», отправить текст и файл.
3. **Один приём сообщений** `channel_webhook`: проверка подписи, запись доставки в `channel_events` (повтор не создаёт дубль), общий обработчик — тот же, что уже работает для Telegram (согласие, бот записи, стоп-слово, вложения).
4. **Отправка** `chat_send` выбирает коннектор по виду канала.
5. **Окно ответа.** Для каналов Meta в базе хранится время последнего сообщения клиента; когда 24 часа прошли, поле ответа в чате закрывается с объяснением (для WhatsApp — предложение шаблона).
6. **Один клиент.** Чаты связываются с контрагентом по телефону; на карточке клиента — список его чатов и выбор канала.
7. **Тесты**: изоляция данных, подписи, повторная доставка без дублей, окно 24 часа, разбор сообщений каждого канала на записанных примерах.

- **Коннекторы**: `connectors/messaging.ts` (общий вид сообщения, кнопки под каждый мессенджер, нумерованный список, если кнопок много, подпись HMAC), `connectors/meta` (Instagram Direct, Messenger, WhatsApp), `connectors/viber`.
- **Сервер**: `channel_webhook` (проверка подписи, подтверждение адреса для Meta, без дублей), `channel_connect` (подключение и отключение владельцем), общий обработчик `inbound.ts` с ботом записи (номер телефона вводится текстом), отправка в `deliverText`, сохранение файлов из мессенджеров в «Документи» (только с серверов Meta и Viber), обновление токена Instagram.
- **Экраны**: настройки каналов — Instagram, Messenger, WhatsApp, Viber с пошаговыми подсказками и адресом для Meta; «Чати» — значки каналов, фильтр по каналу, предупреждение «можно ответить ещё N часов» и закрытое поле ответа после 24 часов; карточка клиента — его чаты во всех мессенджерах.
