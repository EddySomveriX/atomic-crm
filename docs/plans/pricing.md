# «Прайс»: ціни, акції, пакети, сертифікати — итоги

Согласовано 2026-11-16 («Все да»). Ветка `pricing`.

## Решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Цена записи | Запись сохраняет цену на момент записи; новые записи берут новую цену |
| 2 | Цена мастера | Необязательная своя цена у мастера для услуги |
| 3 | Несколько скидок | Действует одна — самая выгодная для клиента |
| 4 | Очерёдность | Цены и акции сейчас; пакеты и сертификаты сейчас, продажа в салоне с отметкой «готівкою / карткою»; продажа онлайн — с monobank (этап 4) |
| 5 | Меню | Раздел «Прайс», модуль включён по умолчанию у услуг и торговли |

## Сделано

- **База** (`supabase/schemas/20_pricing.sql`, миграции `20261119100000_pricing.sql`, `20261119110000_analytics_booking_prices.sql`):
  - у товаров и услуг: категория, «показувати онлайн», порядок, «додаткова послуга»;
  - `price_history` — история цен (пишется сама); `specialist_prices` — цена мастера;
  - `promotions` — щасливі години, останні вікна, перший візит, промокоди (с лимитом использований), срок действия; `companies.personal_discount` — персональная скидка;
  - `price_quote()` — цена услуги для мастера, времени, клиента и промокода с лучшей скидкой;
  - у записи: `list_price`, `price`, акция, промокод, пакет; цена ставится сама при записи и при переносе ещё не выполненной записи;
  - `packages` и `client_packages` — пакеты визитов; запись клиента с пакетом стоит 0, выполненный визит списывает один, отмена выполнения возвращает;
  - `gift_certificates` и `certificate_uses` — сертификаты на сумму или услугу с кодом из 8 знаков; каждое использование — запись, отмена — обратной записью; проданные пакеты, сертификаты и их использования не удаляются;
  - `change_prices()` — изменение цен на % с округлением до гривни (владелец и менеджер);
  - аналитика считает выручку по цене записи.
- **Экран «Прайс»** (`pricing/`): вкладки Ціни · Акції · Пакети · Сертифікати.
  - Ціни: по категориям, цена меняется прямо в строке (Enter — сохранить, Esc — отмена), переключатель «онлайн», «Змінити ціни на %» с предпросмотром, цены мастеров и история цен.
  - Акції: четыре вида, включение и выключение, удаление.
  - Пакети: создание («5 × манікюр»), продажа клиенту, список проданных с остатком визитов.
  - Сертифікати: продажа на сумму или услугу, код, срок, остаток, картинка в цветах бизнеса для отправки в Telegram.
- **Окно записи**: цена со скидкой, «оплачено пакетом», промокод при создании, применение сертификата по коду, «до сплати».
- **Карточка клиента**: персональная скидка, пакеты клиента.
- **Бот и сайт**: цена у каждой услуги; бот перед подтверждением показывает итоговую цену со скидкой; в боте и на сайте только услуги «онлайн», без дополнительных.
