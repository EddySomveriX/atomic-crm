## Решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Где хранить | Закрытое хранилище `documents`, у каждого бизнеса своя папка; открыть файл можно только по временной ссылке |
| 2 | Что принимаем | PDF, JPG, PNG, HEIC, WEBP, Word, Excel до 20 МБ |
| 3 | Дубли | Один и тот же файл хранится один раз (проверка по отпечатку SHA-256) |
| 4 | Фото с телефона | Несколько фото одного бумажного документа собираются в один PDF, страница на фото |
| 5 | Где видно | Раздел «Документи» и блок на карточках контрагента, контакта, угоды и записи |
| 6 | Удаление | Только владелец, через кошик; через 30 дней сервер удаляет навсегда |
| 7 | Модуль | Включён по умолчанию у торговли, производства и B2B; у услуг выключен (включается в настройках) |
| 8 | Распознавание полей | Позже, с AI (этап 5) |

## Сделано

- **База** (`supabase/schemas/21_documents.sql`, миграции `20261120100000_documents.sql`, `20261120110000_message_attachments.sql`, `20261120120000_documents_orphans.sql`):
  - таблица `documents`: вид, название, дата, сумма, файл, отпечаток, источник, привязка к контрагенту, контакту, угоде или записи, кошик;
  - правила: файл лежит в папке своего бизнеса, файл документа не меняется, в кошик и обратно — только владелец;
  - у сообщений чата: вложение клиента (`attachment`) и ссылка на документ (`document_id`);
  - `orphan_document_files()` — файлы без документа (только для сервера).
- **Экран «Документи»** (`documents/`): поиск, фильтр по виду, «Додати документ», кошик владельца с возвратом.
- **Окно «Додати документ»**: «Сфотографувати» (камера телефона) или «Вибрати файл», галочка «Зібрати фото в один PDF», вид, название, дата, сумма; предупреждение о дубле.
- **У каждого документа**: открыть, скопировать ссылку на 7 дней, «Надіслати клієнту в Telegram», «У кошик».
- **Чаты**: файл или фото от клиента в Telegram видно в чате с кнопкой «Зберегти в документи» — он попадает в документы клиента.
- **Сервер**: `document_send` (отправка файла в Telegram), `chat_attachment_save` (сохранение файла из чата), `documents_purge` (очистка кошика старше 30 дней и брошенных файлов; локально раз в час его вызывает `scripts/channels-dev.mjs`).
- Коннектор Telegram: `sendDocument`, `downloadFile`.

## Ограничения

- Отправка документа и сохранение файла из чата проверены до обращения к Telegram; живую проверку с настоящим файлом сделать вместе с владельцем бота.
- Отправка — только в Telegram; клиенту с сайта — ссылкой на 7 дней.
- Telegram не отдаёт боту файлы больше 20 МБ.
- В хранилище путь файла пишется латиницей; настоящее имя файла сохраняется отдельно.
