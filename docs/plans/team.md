# «Команда» — итоги

Согласовано 2026-11-16 («Ок, делай все по порядку»), третий пакет улучшений. Ветка `improvements`.

## Решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Как мастер получает уведомления | Сам подключает Telegram: кнопка в CRM → одноразовая ссылка на бота бизнеса (15 минут) → «Start» |
| 2 | О чём сообщать | Новый, перенесённый и отменённый запись мастера; не сообщать о том, что мастер сделал сам |
| 3 | Процент мастера | Один процент на мастера, ставит только владелец; сумма = выручка выполненных записей × процент |
| 4 | Кто видит отчёт | Владелец и менеджер — всех; мастер — только себя |
| 5 | «Закрити день» | Владелец или менеджер; сначала отмечаются все визиты дня, затем сохраняются итоги; повторное закрытие обновляет итоги |

## Сделано

- **База** (`supabase/schemas/23_team.sql`, миграции `20261122100000_team.sql`, `20261122110000_team_report_list_price.sql`):
  - `members.commission_percent`; `set_member_commission()` — только владелец;
  - `staff_link_codes`, `staff_telegram`, `create_staff_link_code()`, `link_staff_telegram()` (только сервер);
  - `staff_notifications` и триггер на записях — очередь сообщений мастерам;
  - `team_report(from, to)` — визиты, неявки, выручка, процент и сумма по мастерам (записи без цены считаются по цене прайса, как в аналитике);
  - `day_closings` и `close_day(day)`.
- **Бот**: ссылка `/start staff_<код>` привязывает чат мастера; `staff_notify` отправляет очередь (локально — каждые несколько секунд из `scripts/channels-dev.mjs`).
- **Экран «Команда»** (меню «Запис» → «Команда», на телефоне — кнопка на календаре): «Мій Telegram», отчёт за этот месяц, прошлый месяц или неделю, процент мастера в строке.
- **«Сьогодні»**: карточка «Закрити день» для владельца и менеджера — отметка «Прийшов / Не прийшов» по каждому визиту, итоги дня и суммы мастерам.
- Роль «менеджер» теперь различается в интерфейсе (раньше считалась обычным сотрудником).

## Ограничения

- Живую привязку проверить вместе с владельцем бота: «Команда» → «Підключити Telegram» → «Відкрити бота» → «Start».
- Процент — один на мастера; разные проценты для разных услуг — позже.
- Визиты по пакету идут с ценой 0, процент с них не начисляется.
- Оплаты (наличные, карта) появятся с этапом 4; сейчас итоги дня — по ценам записей.
